把记账本装到桌面
这一步把记账本 App 放到你的手机桌面上，以后点开就能用。
📒 先打开记账本 💾 另存文件
💡 打开后怎么办？
1. 打开后，点 Safari 底部中间的「分享按钮」（方框向上箭头）
2. 往下滑找到 「添加到主屏幕」 → 点右上角「添加」
3. 桌面就有记账本图标了！以后点桌面图标打开
✅ 我已经把记账本加到桌面了
🎉 太棒了！记账本图标已经在你桌面上了～
2
创建仓库（存数据用）
点下面按钮跳转到 GitHub，创建一个仓库来永久保存你的记账数据。
🏗️ 点这里 → 创建仓库
https://github.com/new?name=family-accounts&private=1&description=Nicole家庭记账本备份&auto_init=1
💡 打开后怎么做？
1. 如果让你登录，就输 GitHub 密码登录
2. 什么都不用改！直接滑到屏幕最底部
3. 找到大大的绿色按钮「Create repository」，点它！
4. 看到新页面就算成功，然后回到本页继续
✅ 仓库创建成功了
✅ 仓库准备好了！用来永久保存你的记账数据～
3
获取密钥（让App能备份）
点下面按钮创建一串「密钥」，复制后粘贴到记账本里就行。
🔑 点这里 → 创建密钥
https://github.com/settings/tokens/new?scopes=repo&description=记账本备份永久有效
⚠️ 这一步非常重要！仔细看
1. 打开后什么都不用改，滑到最底部
2. 找到绿色按钮「Generate token」→ 点它
3. 看到一串绿色的字母数字（ghp_开头）
4. 👉 用手指长按那串字母 → 全选 → 拷贝（复制）
5. 复制好后，回到桌面打开「记账本」App
✅ 密钥已经复制好了
🔑 密钥到手！还差最后一步～
4
粘贴密钥 & 备份
打开桌面的记账本 App，把复制的密钥粘进去，就完成啦！
📝 一步步做
1. 打开桌面上的「记账本」App
2. 点右下角「⚙️ 设置」→「☁️ GitHub 备份」
3. 看到第三行「Token 访问密钥」输入框
4. 👉 长按输入框 → 「粘贴」
5. 点「💾 保存配置」→ 看到成功提示
6. 点「⬆️ 立即备份」→ 等几秒
7. 看到「✅ 备份成功」就全部搞定了！
🎉 全部搞定！记账本可以用了
